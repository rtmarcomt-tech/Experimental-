# Digital Creator Marketplace

Aplicação de marketplace digital multi-criador.

> Estado: fundação técnica em desenvolvimento. Não utilizar em produção.

## Requisitos confirmados
- Venda individual de fotografias e vídeos.
- Conteúdos gratuitos e pagos.
- Criadores sujeitos a validação administrativa antes de vender.
- Comissão inicial de 10%.
- PayPal para pagamentos dos compradores; não implementar Stripe.
- Retenção configurável dos valores devidos e pagamentos posteriores aos criadores.
- Sem produtos físicos, portes, pacotes ou subscrições nesta fase.

## Stack
Laravel + PostgreSQL + Redis + armazenamento privado compatível com S3.
